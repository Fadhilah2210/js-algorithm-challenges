# JavaScript Core Algorithms

A collection of programmatic problem-solving implementations developed in JavaScript.

## Contents
1. **Prime Number Checker**: Validates whether a number is prime using optimized trial division.
2. **Duplicate Element Finder**: Isolates duplicate entries from a dataset using ES6 `Set` data structures (`seen` and `duplicate` sets).
3. **Leap Year & Age Calculator**: Computes exact age intervals and filters Gregorian leap years within a specific date range.

## Technologies Used
* JavaScript (ES6+)
* Node.js Runtime Environment
